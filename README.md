# Snake Game
This is my rendition of the old nokia snake game.\
Visit [snake game](https://shiny-sunburst-1efe0c.netlify.app/).
<p align="left"><img width="500" height="600" alt="Screenshot of snake game landing page." src="https://github.com/user-attachments/assets/c163e3e8-ac21-4188-bb1e-4d4232fa3674" /></p>

## How to play
- Use the **Arrow Keys** to control the snake.
- Eat the red food to increase your score.
- The snake grows longer each time it eats food.
- Avoid hitting the walls.
- Avoid running into the snake's own body.
- The game ends when the snake collides with itself or the wall.
